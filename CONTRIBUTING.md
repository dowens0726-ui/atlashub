# Contributing to AtlasHub

Thank you for helping improve AtlasHub.

AtlasHub is built as a premium GTA VI companion platform with a focus on speed, clarity, maintainability, and player experience.

---

## Project Philosophy

Every feature should support the core mission:

> Spend Less Time Searching. More Time Playing.

Before adding something new, ask:

- Does this help players find useful information faster?
- Does this improve the Atlas experience?
- Does this keep the codebase easier to maintain?

```txt
app/
