# AtlasHub Decision Log

## ADR-001 — Documentation is a First-Class Feature

Date: 2026-06-28

Status: Accepted

### Decision

AtlasHub documentation will evolve alongside the code.

Every significant product, architecture, or workflow decision should be reflected in the appropriate documentation.

### Reason

Documentation gives AtlasHub continuity across development sessions.

It helps future contributors understand not just what was built, but why decisions were made.

### Impact

- `PROJECT_CONTEXT.md` becomes the project source of truth.
- `docs/SPRINT.md` tracks current sprint work.
- `docs/ARCHITECTURE.md` tracks technical structure.
- `docs/DECISIONS.md` records major decisions.
- `docs/SESSION_LOG.md` records development sessions.
