# AtlasHub Design System

Version: Alpha 1.0

---

# Vision

AtlasHub should feel like software that could have shipped alongside GTA VI.

Not a fan website.

Not a wiki.

A premium companion platform.

Our design goals are:

- Fast
- Premium
- Minimal
- Intelligent
- Data-driven
- Comfortable for long sessions

---

# Design Principles

## 1. Information First

The UI should never compete with the information.

Content is always the hero.

---

## 2. Premium Dark Theme

AtlasHub should feel modern without looking futuristic.

Think:

- Discord
- Linear
- Arc Browser
- Notion
- GitHub Dark

Avoid:

- Neon
- Overly saturated colors
- Heavy gradients
- Loud shadows

---

## 3. Every Screen Has One Purpose

Dashboard
→ Understand your empire

Planner
→ Decide what to do next

Profile
→ Manage your empire

Explorer
→ Discover content

Advisor
→ Receive recommendations

---

# Components

Every component should answer:

What action does this help the player perform?

---

# Dashboard

Should feel like an aircraft cockpit.

Large metrics.

High information density.

Clear hierarchy.

---

# Profile

Should feel like an Empire Control Center.

Editing should be enjoyable.

---

# Planner

Should feel like a strategy board.

Everything should encourage progression.

---

# Advisor

Should feel like an experienced GTA player giving advice.

Never generic.

Always explain WHY.

---

# Activity

Should tell the story of the player's empire.

Every action matters.

---

# Achievements

Progress should always be visible.

Locked achievements should still inspire.

---

# Empty States

Every empty state should encourage action.

Never simply say:

"No data."

Instead:

"Start building your empire."

---

# Mobile

Desktop first.

Tablet second.

Mobile always supported.

---

# Accessibility

Minimum AA contrast.

Keyboard navigable.

Visible focus states.

Semantic HTML.

---

# Performance Goals

First load:

<2 seconds

Navigation:

Instant

Search:

<100ms

Interactions:

Immediate

---

# Product Philosophy

AtlasHub is not a database.

AtlasHub is a strategy platform.

Every feature should answer:

"What should the player do next?"

If it doesn't...

It probably doesn't belong.
