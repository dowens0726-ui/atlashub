# AtlasHub v1.0 Roadmap

## Goal

Build AtlasHub into a personalized GTA companion that helps players decide what to do next, why it matters, and how to execute the best session strategy.

---

## Current Status

AtlasHub currently includes:

- Command Center dashboard
- Player profile and persistent empire state
- Atlas AI panel
- Next Best Action system
- Advisor reasoning
- Session strategy reasoning
- Intelligence feed
- Empire scoring
- Live profile updates
- Search, vehicles, weapons, missions, businesses, rankings, map, and planner foundations

---

## Milestone 1 — Atlas Copilot

Goal: Make Atlas feel like a personal strategist.

Deliverables:

- Dynamic greeting
- Daily briefing
- Next Best Action refinement
- Recommendation reasoning
- Session strategy explanation
- Empire forecast summary

Definition of Done:

- User opens dashboard and understands their best move in under 5 seconds.

---

## Milestone 2 — Empire Simulator

Goal: Let users test decisions before committing.

Deliverables:

- What-if purchase simulator
- Empire score projection
- Cash remaining projection
- Income impact estimate
- Risk assessment
- Recommendation comparison

Definition of Done:

- User can ask “What if I buy this?” and see projected impact.

---

## Milestone 3 — Atlas Memory

Goal: Make Atlas remember player progress.

Deliverables:

- Timeline
- Decision history
- Expanded activity feed
- Achievement triggers
- Player behavior profile

Definition of Done:

- Atlas can show meaningful history and progression over time.

---

## Milestone 4 — World Intelligence

Goal: Make the map and explorer smarter.

Deliverables:

- Map intelligence panel
- Marker recommendations
- Route planning foundation
- Location-based activity suggestions

Definition of Done:

- Map is useful for planning, not just browsing.

---

## Milestone 5 — Beta Polish

Goal: Prepare for public testing.

Deliverables:

- Mobile polish
- Loading states
- Empty states
- Error states
- SEO pass
- Content quality pass
- Visual consistency pass

Definition of Done:

- AtlasHub feels stable enough to share with testers.

---

## Milestone 6 — Public Alpha

Goal: Launch a usable public alpha.

Deliverables:

- Vercel production deployment
- Feedback capture
- Changelog
- Roadmap page
- Disclaimer / data policy
- Initial marketing landing page

Definition of Done:

- Public users can visit, understand the value, and give feedback.
