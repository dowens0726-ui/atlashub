# Sprint 0.4 — Atlas Compare

## Goal

Build the first comparison system and continue improving the application architecture.

## Completed

- Vehicle comparison
- Winner highlighting
- Price comparison
- Homepage refactor
- Global navigation
- AtlasStats
- Homepage components

## Lessons Learned

- Modular components are easier to maintain.
- Keeping routes and reusable components separate prevents import issues.
- Replacing an entire file is often safer than patching long JSX files.
