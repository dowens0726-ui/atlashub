# The Atlas Manifesto

Atlas exists because gamers deserve better.

For too long, finding information about games has meant opening dozens of browser tabs, scrolling through ad-filled articles, watching ten-minute videos for thirty seconds of information, or searching through forums hoping someone already asked the same question.

We believe there is a better way.

Atlas is built on one simple idea:

Spend Less Time Searching.
More Time Playing.

Every feature we build should help players make better decisions, faster.

We don't chase clicks.

We don't build pages for search engines.

We build tools that gamers genuinely want open while they play.

Trust is more important than traffic.

Quality is more important than quantity.

Players come before profit.

Atlas is not trying to become the biggest game guide.

Atlas is trying to become the most useful gaming companion ever built.

Every decision we make should move us closer to that goal.
