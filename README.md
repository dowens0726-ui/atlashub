# 🧭 AtlasHub

> **Spend Less Time Searching. More Time Playing.**

AtlasHub is a premium companion platform for **Grand Theft Auto VI**, designed to help players quickly discover vehicles, weapons, missions, businesses, collectibles, interactive maps, and intelligent recommendations.

Built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**, AtlasHub focuses on delivering a fast, intuitive, and visually polished experience for GTA players.

# 🚀 Running Locally

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AtlasHub.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```
